# 📜 Commands

## 🎲 Randomizer

* `/dbd roll`

## 📖 Wiki

* `/dbd wiki`

## ⭐ Favorites

* `/dbd fav perks`
* `/dbd fav character`
* `/dbd fav clear`

## 🏗️ Builds

* `/dbd build create`
* `/dbd build menu`
* `/dbd build import`

## 🔍 Search & Statistics

* `/dbd search`
* `/dbd perks`
* `/dbd stats`

## 🎁 Utilities

* `/dbd codes`
* `/dbd info`
