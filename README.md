# 📜 Commands

## 🎲 Randomizer

* `/dbd roll`

## 📖 Wiki

* `/dbd wiki`

## ⭐ Favorites

* `/dbd fav perks`
* `/dbd fav character`
* `/dbd fav clear`

## 🏗️ Builds

* `/dbd build create`
* `/dbd build menu`
* `/dbd build import`

## 📊 Statistics

* `/dbd stats`
* `/dbd perks`
* `/dbd search`

## 🎁 Utilities

* `/dbd codes`
* `/dbd info`
